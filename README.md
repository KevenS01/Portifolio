KEY3D - Site de Loja de Impressão 3D

Estrutura:
- index.html
- produtos.html
- sobre.html
- contato.html
- css/style.css
- img/logo.svg
- img/luffy.png
- img/dragao.png
- img/rayquaza.png
- img/patolino.png

O site foi feito com HTML e estilizado com CSS externo (css/style.css).
Atende aos requisitos da atividade:
- 4 páginas HTML interligadas;
- header, nav, main, section, article e footer;
- lista ordenada e não ordenada;
- tabela com 4 linhas de dados;
- formulário com vários tipos de campos e campos required;
- 3 imagens com alt dentro da pasta img;
- âncoras internas;
- comentários explicando section e article.

IMPORTANTE:
A imagem enviada nesta conversa foi apenas a imagem da atividade. Como a segunda imagem (logo) não foi anexada, foi criado um logo provisório em img/logo.svg. Quando a segunda imagem for enviada, ela pode substituir esse arquivo.
